# 📝 To-Do List

A simple and responsive **To-Do List web application** built using **HTML, CSS, and JavaScript**. Users can add, complete, and delete tasks, with tasks automatically saved using **Local Storage**.

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Save tasks using Local Storage
* Tasks persist after page refresh
* Clean and responsive UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
